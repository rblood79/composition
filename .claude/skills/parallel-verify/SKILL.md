# 패밀리 병렬 검증

사용자가 병렬·위임을 명시한 범위에서만 실행합니다. 단일 컴포넌트는 `cross-check`를 사용합니다.

현재 catalog에서 영향받은 컴포넌트를 패밀리별로 묶고 독립적으로 검사할 범위를 나눕니다.
각 에이전트에 컴포넌트·파일 소유권, 읽기/수정 권한, 완료 기준을 명시합니다.
다른 작업자의 변경을 보존하도록 알립니다. 공용 renderer 파일의 수정은 한 담당자가 소유합니다.

검증 계약은 `cross-check`와 해당 레이어 참조를 사용합니다. 각 에이전트는 관찰한 경로·
이슈·실행 근거와 미검증 범위를 반환합니다. 결과를 통합하고 겹치는 이슈를 정리합니다.
검증만 요청되면 보고하고, 수정까지 요청되면 소유 범위의 문제와 관련 검증까지 완료합니다.
