# catalog 부품 — picker 의 선택 목록 · 달력 · Menu (ADR-253 · 256)

> 2026-11-21 (ADR-315 Phase 7) 규칙 문서 크기 상한 (`pnpm docs:rule-size`) 때문에 원문 그대로 옮겼다. 규칙 파일에는 요약과 이 파일 링크가 남는다. 이 기능을 고치기 전에 읽는다.

원래 자리: [catalog-subparts.md](../../../rules/catalog-subparts.md).

- **picker 의 선택 목록 (ADR-253 Phase 4, 2026-10-07)**: Select · ComboBox 의 항목은 그 안의 ListBox — ListBox 원본의 instance — 의 slot 채움이다 (library `slotFills`). Select · ComboBox 의 ListBox 는 Popover 노드 안에 있다 (ADR-256 Phase 6c · 6d — `Select > … + Popover > ListBox` · `ComboBox > Label + Group(Input + Button) + … + Popover > ListBox`, Preview 는 RAC Select · ComboBox 안에서 자식을 순서대로 그린다). DatePicker · DateRangePicker 의 달력 (Calendar · RangeCalendar 원본의 instance) 은 S2 `CalendarPopover` 처럼 `Popover (여백 0) > Dialog (여백 24 · 16) > 달력` 이고 Popover 는 도움말 앞이다 (2026-11-18 — 그전 6e 는 Dialog 없이; S2 의 여백 `div` 는 Dialog 의 여백, 이름은 picker 의 `DialogContext` — 대체 이름 없음) — 달력 binding 은 picker 안에서 자기 값 · 상태를 넘기지 않아 RAC 의 달력 context 가 이기고, 크기 · `firstDayOfWeek` · `pageBehavior` · min/max 는 picker 의 것, `visibleDuration` · `weeksInMonth` 는 안 Calendar 노드의 것 (picker ↔ 달력 조회는 Dialog 를 건넌다 — Canvas `calendarPicker` · DOM `catalogCalendarPicker`). 시각 단위 picker 의 Dialog 는 달력 뒤에 `frame > TimeField` (range: 시작 · 끝) 를 갖고, day 단위면 둘 다 없다 (`catalogPickerTimeAbsent`); TimeField 의 값 · 단위 · 시간제 · 경계는 picker 의 것 (DOM RAC `TimeFieldContext` ← picker 상태, Canvas `catalogPickerTimeFieldOf`). 달력 노드 트리는 S2 `Calendar.tsx` 의 것 — `CalendarHeader (머리 줄) > CalendarMonth (달별 제목 묶음, 반복)` + `frame > CalendarGrid (반복 — CalendarMonth 밖 grid 는 resolver 가 달마다 복사, 2026-11-18)`. DOM 은 ListBox 노드의 요소를 RAC Popover 안에 그리고 (RAC `ListBox` 그대로 — 이름 · 선택 · focus 는 RAC 의 Select · ComboBox context 소유, D1), Canvas 는 닫힌 목록을 그리지 않는다 (`presence.ts` `TRIGGER_OVERLAY_CHILDREN`). 항목을 picker 루트의 직계 자식으로 두지 않는다 — 항목의 소유자 계약 (`componentTraits.ts` `ListBoxItem.owners: ["ListBox"]` → `nestingRules.ts` `RAC_SUBPART_OWNER_TYPES`) 이 막는다 (옛 renderer 한계 표는 ADR-256 Phase 11 에서 삭제했다 — 모든 family 가 노드 트리로 그린다). 항목의 선택 표시는 picker Popover 안 sheet 글리프 (RAC 레퍼런스 `.dropdown-item` 의 lucide check — ListBox rule `rootSelectors["&:is(.react-aria-Popover *)"]` 의 `[data-selected]::before`, 생성 `ListBox.css`. 수동 `ListBox.css` 팝오버 규칙은 Builder 자체 picker 전용 `:not([data-catalog-id])` — 2026-10-13) 가 기본이고, 작성자가 항목에 `showWhen: isSelected` 노드를 넣으면 그 노드가 RAC 의 선택을 따르고 글리프가 비킨다 (`data-selection-mark` — MenuItem 과 같은 길, 6f). **Autocomplete** (ADR-256 Phase 6g) 는 RAC `Autocomplete` 그대로 요소가 없다 — 원본 `Autocomplete > SearchField + ListBox`, Canvas 는 rule 의 `display: contents` (엔진 구현) 로 자식을 부모 흐름에 세운다. **Menu** (ADR-256 후속 4, 2026-10-09) 도 레퍼런스대로 `MenuTrigger > Button + Popover > Menu` 다 — Menu 노드는 어디에 있든 RAC `Menu` (목록 — Canvas 도 목록으로 그린다), trigger 는 Button 노드 (모양은 Button rule), 닫힌 목록은 MenuTrigger 의 Popover (`TRIGGER_OVERLAY_CHILDREN.MenuTrigger`). MenuTrigger · DialogTrigger · TooltipTrigger 노드는 RAC 처럼 요소가 없다 — DOM 은 자식만, Canvas 는 rule 의 `display: contents` (ADR-256 G5 예제 2 · 9, 2026-10-12 — 전에는 ADR-255 의 배치 `div`). 요소가 없는 노드 (rule 루트 `display: contents`, 그리고 DOM binding 이 요소를 만들지 않는 RAC 부품 — TreeItemContent · SideNavItemContent · SubmenuTrigger · CalendarMonth/YearPicker, 그리고 자식이 있는 FileTrigger — Canvas 도 `display: contents` · 칠 없음 (2026-11-14), S2 Skeleton (ADR-314 — 내용을 감싸는 로딩 context, 원본 루트 = slot `Content`, 빈 Skeleton 은 Canvas 만 점선 자리 `catalogEmptySkeleton`), `catalogElementlessType`) 의 Design 패널 Layout · Style · Text 탭은 안내만 내고 Canvas 간격 손잡이도 뜨지 않는다 (Screen 은 남김, 2026-11-13 전수 감사 — 전에는 패널이 편집을 받고 Canvas 에만 그렸다). **Why (2026-10-15)**: Canvas 한 번 클릭은 instance 인 MenuTrigger 를 고르고, 그 Radius · Border 편집은 MenuTrigger record 에만 쓰여 어디에도 그려지지 않았다 (사용자 보고 「button radius 적용 안 됨」). Autocomplete 안 Menu 는 열린 목록이고 입력값이 거른다 (G0 예제 4). 하위 메뉴는 `SubmenuTrigger > MenuItem + Popover > Menu` (Design "+" 가 한 번에 넣는다) — MenuItem 안 MenuItem 은 하위 메뉴가 아니다. 사용할 수 없는 항목은 S2 이름 그대로 `UnavailableMenuItemTrigger > MenuItem + Popover > frame > Heading[slot=title] + Content` (S2 체크리스트 §9.3, 2026-11-23 — 같은 "+" 가 넣는다): `isUnavailable` 이면 DOM 은 RAC `SubmenuTrigger` (누르면 도움말, Popover 이름 = 제목 Heading 의 HTML id), 아니면 항목만. 정보 아이콘은 MenuItem 원본의 `slot=descriptor` 노드 (`showWhen: isUnavailable` — composition 상태 키, `unavailableMenuItem.ts`), DOM 은 항목의 상태 frame 에 `isUnavailable` · `hasSubmenu: false` 를 얹어 꺾쇠 대신 그것을 그리고, trigger 의 prop 편집은 `catalogStateDependents` 가 안 조건부 노드를 다시 판정한다. MenuItem 은 S2 `menuitem` grid (2026-11-18): 열 = 선택 표시 · 아이콘 · 라벨 (설명은 그 아래 줄) · 단축키 · chevron (`slot=descriptor`), column gap 0 · 간격은 부품 margin — MenuItem rule 의 `staticSelectors` · `sizeSelectors` 가 정본 (선택 부품은 library 조립 때 ListBox 항목에서 복사 — `selectionItemTemplates.ts`, 배치는 rule). Section 머리 = `Header > Heading + Text[slot=description]`, 「+ Section」 은 Section 뒤 Separator 를 같이 넣고 Menu 안 Separator 는 첫 자리 · 끝 자리 · 다음이 Separator 이면 숨는다 (`catalogMenuSeparatorHidden` — S2 `isSeparatorHidden`).
