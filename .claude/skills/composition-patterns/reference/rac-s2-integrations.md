# RAC · S2 연동 기능 전수 목록 — 빌더 지원 현황

> 사용자 지시 (2026-10-23): 「레퍼런스의 연동 기능 모두 놓치는 것 없이 학습하고 담아 둬야 한다」. 빌더 사용자가 어떤 구성을 할지 모르므로 레퍼런스가 제공하는 연동은 전부 지원 대상이다. 새 연동을 설계하기 전에 이 표에서 레퍼런스 이름 · 모양을 먼저 찾는다 — 레퍼런스에 있는 것은 그 이름 그대로 (`useListData` · `useAsyncList` · `RouterProvider` · `loadingState` …), 없는 것만 composition 확장 (`d2Provenance.ts`).

- **출처**: 로컬 공식 스냅샷 전부 — `.claude/skills/react-aria/references/` (guides 12 · utilities 19 · interactions 18 · components 53 + hook 문서) · `.claude/skills/react-spectrum/references/` (components 71 · guides). 문서와 설치본이 다르면 **설치본이 정본** (RAC = D1, S2 1.8.1 = D2).
- **연동 기능**: 컴포넌트를 데이터 · 상태 · 라우팅 · 폼/서버 · 비동기 로딩 · 다른 컴포넌트에 잇는 것. 순수 스타일 · 접근성 이름 · press/hover 같은 기본 interaction 단위는 뺐다.
- **빌더 열**: ✅ 지원 · ◐ 부분 · ✗ 없음 · ? 코드로 확인 못 함 (지원으로 간주 금지). 빌더 쪽 이름: 바인딩 = `NodeEntry.binding` (`DataBindingRef`), 규칙 = `InteractionEntry` (When · Do), 개념 = `packages/shared/src/interactions/concepts/*.ts`, 세션 = `catalogPreviewSession.ts`.
- **스냅샷 공백** (문서에 없어 설치본으로 확인할 것): `useListData` · `useAsyncList` · `useTreeData` 의 Options · Interface 표가 비어 있다 (메서드는 예제에서만). `useListData.getItem` · `filterText` · `setFilterText`, `useAsyncList` 의 `error` · `sort()` 는 문서에 없고 설치본 (react-stately) 에 있다. S2 `LoadingState` 값은 문서에 `loading` · `loadingMore` 만, 설치 타입은 `loading | sorting | loadingMore | error | idle | filtering`.

갱신: 연동을 추가 · 변경하면 해당 행의 빌더 열을 같은 커밋에서 고친다.

## 12. 빈 칸 우선순위 (빌더 기본 CRUD · 목록 화면 기준)

이 순서는 이 표에서 뽑은 판단이고 결정이 아니다. 착수 전 사용자 확인 (D2 이름은 위 레퍼런스 그대로):

1. 빈 상태 `renderEmptyState` (`loadMore` · `cursor` · 목록 끝 자동 `onLoadMore` 는 2026-10-23 추가)
2. 서버 검증 오류 Form `validationErrors` (제출 응답 → field)
3. 검색 — Autocomplete 서버 검색 확인 · `useListData` `filter` (로컬) (ComboBox ↔ `filterText` · `setFilterText` · 서버 정렬은 2026-10-23 추가)
4. 컬렉션 DnD (`useDragAndDrop` — `onReorder` · `onInsert` 를 이미 있는 `move*` · `insert*` 에) (`useListData` 위치 편집은 2026-10-23 추가)
5. Toast 종류 · timeout · action, Button `isPending` 자동 연결
6. `useTreeData` · Table `treeColumn` 펼침 행 · TableFooter · S2 `renderActionBar`

관련: [state-management.md](../../../rules/state-management.md) §4 · §6 (바인딩 · Do 의 현재 구현), [ssot-hierarchy.md](../../../rules/ssot-hierarchy.md) §1 D2 (이름 정본 순서).
