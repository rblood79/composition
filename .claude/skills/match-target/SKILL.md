# 참조 화면에 맞추기

참조와 현재 화면을 같은 viewport·theme·상태에서 비교하고 요청한 시각 결과까지 조정합니다.
대상은 현재 UI에서 찾습니다. DOM selector나 반복 횟수를 사용자에게 필수 입력으로 요구하지 않습니다.
참조 자체가 없거나 의도가 크게 달라지는 경우에만 필요한 정보를 질문합니다.

변경은 요청한 컴포넌트의 catalog·token·스타일 경로에 한정합니다. DOM/API 계약까지
바뀌어야 한다면 영향을 먼저 설명하고 기존 승인 범위로 가능한지 판단합니다.
각 조정 후 실제 화면에서 크기·간격·색·정렬·타이포 차이를 확인합니다.
주관적인 0~1 유사도 점수를 측정치나 자동 종료 조건으로 사용하지 않습니다.

진전이 없으면 레이어·입력 상태·측정 환경의 원인을 조사합니다. 임의 반복 횟수를 채우지 않습니다.
사용자가 정한 시간·횟수 한도가 있으면 준수합니다. 최종 화면과 남은 차이·검증 근거를 보고합니다.
Canvas/Preview를 함께 바꿨다면 `cross-check`로 정합성을 확인합니다.
