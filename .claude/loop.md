`.agent/task-state.json` 의 `next` 에서 끝나지 않은 항목을 위에서부터 하나 골라 이어서 진행한다.

- `guard` · `stop` 을 지킨다. 항목이 끝나면 `[x]` 로 표시하고 `updatedAt` 을 갱신한다.
- PR 은 만들지도 살피지도 않는다 (`.claude/rules/git-workflow.md`). 커밋 · push 는 사용자가 요청했을 때만 한다.
- 정리 작업 (버그 탐색 · 단순화 · 경고 줄이기) 을 스스로 시작하지 않는다.
- 남은 항목이 없거나 사용자 결정이 필요한 항목만 남았으면 한 줄로 보고하고 loop 를 끝낸다.
