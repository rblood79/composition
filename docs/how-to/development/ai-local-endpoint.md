# AI 어시스턴트에 로컬 endpoint 연결하기

composition 의 AI 어시스턴트는 **모델을 내장하지 않는다**. 어느 모델을 쓸지는 사용자가
정하고, 키는 사용자가 가진다 (BYOK). 그리고 지금 브라우저에서 쓸 수 있는 경로는
**로컬·사설망 endpoint 하나뿐이다** — 원격 상용 provider 직접 호출은 차단돼 있다
([ADR-134](../../adr/134-ai-assistant-llm-infrastructure-unification.md) HC13/R12).

> **왜 차단인가**: 브라우저에서 원격 provider 를 직접 부르면 API 키가 클라이언트 번들과
> 네트워크 요청에 노출된다. 정식 경로는 프록시이고, 프록시는 아직 없다. 그때까지 원격
> endpoint 를 프로파일에 넣으면 `remote-provider-requires-proxy` 로 호출 전에 막힌다.

## 1. 로컬 endpoint 띄우기

Ollama 기준 (vLLM · LM Studio · 사내 gateway 도 **OpenAI 호환 endpoint 면 그대로 된다** —
전용 어댑터가 없다):

```bash
# 설치 후
ollama serve                 # http://localhost:11434
ollama pull qwen3:14b        # 도구 호출을 지원하는 모델을 고른다
```

OpenAI 호환 경로는 `http://localhost:11434/v1` 이다. `/v1` 을 빠뜨리면 404 가 난다.

### 모델 고르기

도구 호출(function calling)을 지원하는 모델이어야 한다. 지원하지 않으면 어시스턴트가
계속 설명만 하고 캔버스를 바꾸지 않는다. 모델 품질은 사용자 선택 영역이고 제품이 보증하지
않는다 (ADR-134 R10).

## 2. 프로파일 설정

AI 패널 헤더의 **톱니 아이콘** → 프로파일 설정.

1. 프리셋 **로컬 (Ollama)** 를 누르면 endpoint 가 채워진다.
2. **모델** 칸에 실제 모델 이름을 적는다 (`qwen3:14b` 등).
   - 모델 칸이 비어 있으면 그 프로파일은 **미구성**이다. 제품이 기본 모델 id 를 채워 넣지
     않는 이유는, 하드코딩한 id 가 만료돼 404 로 패널 전체가 조용히 멈춘 적이 있어서다.
3. 로컬 endpoint 는 보통 키가 필요 없다 — **키 이름** 칸은 비워 둔다.

### 역할별로 다른 모델 쓰기

프로파일은 5개다: **기본 / 계획 / 실행 / 검증 / 분류**.

| 프로파일 | 하는 일                             | 고를 때 기준           |
| -------- | ----------------------------------- | ---------------------- |
| 계획     | 요청을 단계로 쪼갠다                | 추론이 센 모델          |
| 실행     | 도구를 실제로 부른다                | 도구 호출이 정확한 모델 |
| 검증     | 결과가 요청대로인지 본다            | 가볍고 판단이 보수적인 것 |
| 기본     | 위 셋이 없을 때 대신 쓴다           | —                      |

**계획 프로파일을 설정하면** 여러 단계가 필요한 요청이 계획 → 실행 → 검증으로 나뉘어
처리되고, 검증에서 빠진 것이 발견되면 최대 두 번까지 스스로 고친다. 설정하지 않으면 기존처럼
한 번에 처리한다. 설정하지 않은 역할이 어디로 내려가는지는 설정 화면의 연결 상태에
그대로 표시된다 — *계획 → 기본* 처럼 보이면 계획 프로파일이 아직 비어 있다는 뜻이다.

## 3. 키를 쓰는 경우

사내 gateway 처럼 키가 필요한 로컬·사설망 endpoint 라면:

1. **키 이름** 에 식별자를 적는다 (예: `GATEWAY_TOKEN`).
2. **키 값** 칸에 값을 넣는다. 입력하면 칸은 비워진다.
3. 기본은 **이 세션에서만** 기억한다. 브라우저에 남기려면 *키 보관* 을 켜야 하고, 끄면 저장된
   값이 즉시 지워진다.

프로파일 설정 자체(endpoint · 모델 · 키 **이름**)는 브라우저에 저장되지만 **키 값은
설정과 함께 저장되지 않는다**.

## 4. 안 될 때

| 증상                                     | 원인                                                                 |
| ---------------------------------------- | -------------------------------------------------------------------- |
| "에이전트 프로파일 미구성"               | 모델 칸이 비어 있다                                                  |
| 요청해도 아무 일도 안 일어남              | 모델이 도구 호출을 지원하지 않는다                                   |
| `remote-provider-requires-proxy`         | endpoint 가 로컬·사설망이 아니다 (프록시 도입 전까지 차단)          |
| 404                                      | endpoint 에 `/v1` 이 빠졌거나 모델 이름이 서버에 없다                |
| 계획을 설정했는데 *계획 → 기본* 으로 표시 | 계획 프로파일의 모델 칸이 비어 있다                                  |

로컬·사설망 판정 범위: `localhost` · `127.0.0.1` · `::1` · `*.local` · `10.*` ·
`192.168.*` · `172.16~31.*`.
