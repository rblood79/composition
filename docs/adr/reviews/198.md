### 근본 반론 (hate)

- **load-bearing 가정**: 소프트웨어 래스터로 캡처한 Skia 레그가 사용자가 보는 Builder 화면을 대변한다 (`ADR:129-134` HC4 가 `surfaceBackend: "sw"` 강제).
- **root**: 프로덕션 Builder 는 `MakeWebGLCanvasSurface` (Ganesh/GL) 로 그린다 (`createSurface.ts:29`, `SkiaRenderer.ts:1126`). AA·gradient dithering·blur/shadow·clip edge 의 SW↔GL 차이가 L3 예산 (≤0.001) 을 넘으면 **게이트는 녹색인 채로 사용자 가시 발산이 남는다** — 게이트가 증명하는 명제와 ADR 이 주장하는 명제가 다르다. 공격 축: 측정 leakage (`measurement-validity.md` §2 #3 shared hallucination — 게이트가 자기 조건에서만 참인 등가를 확인).
- **first nail**: 파일럿 픽스처 1개를 같은 pinned Chromium 에서 `ck.MakeSurface` 와 `ck.MakeWebGLCanvasSurface` 양쪽으로 렌더해 `maxByte`/`changedFraction` 을 잰다 — 캡처 1회 추가, 분 단위. 프로그램은 Phase 0~6 + CI + 픽스처 매트릭스 + ledger 이므로 nail 이 압도적으로 싸다.
- **판정**: 어느 Gate 도 미커버 → 이슈 HIGH-1. `1f4b68302` 에서 R13 신설 + HC4 전제 명시 + Phase 0 task 8 + G0 차단 조건으로 **fixed**.
