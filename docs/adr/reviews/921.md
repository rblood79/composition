### 이슈 상세

**LOW-1 (other)**: breakdown §3-2 헤더 필수 필드가 `projectionVersion` 과 `layoutVersion` 을 병기하는데 `projectionVersion` 의 정의가 없다. 현행 코드 convention 은 `projectionVersion = sceneSnapshot.sceneVersion` 복합체 (layoutVersion + **pagePositionsVersion** + projection content signature, ADR-136 계보 — rendererInput.ts:74,187,352 / buildSceneSnapshot.ts:231-242) 이므로 이 등식을 따르면 page 이동 무효화가 커버되지만, breakdown 만 읽은 구현자가 projection-only 카운터로 만들면 page 이동 시 stale world bounds 가 된다. 헤더 표에 "projectionVersion = 현행 sceneVersion 계보 (ADR-136 3-요소 복합)" 1줄 명시 권장.

**LOW-2 (other)**: breakdown §8-1/Phase 3 의 "단일 rollout flag" 가 정의처를 명시하지 않는다. canvas-rendering.md §10 (2026-08-15) 이 canvas 게이트/플래그의 유일 정의처를 `wasm-bindings/featureFlags.ts` (registry 계약 테스트 기계 집행) 로 고정했으므로, rollout flag 도 registry 경유임을 1줄 명시 권장.

**LOW-3 (other)**: ADR 이 링크한 PENCIL_ECOSYSTEM_ANALYSIS.md:11,24 는 openpencil local snapshot 에 ".git 이 없어 exact commit 미확정" 이라 쓰지만, 현재 checkout 은 git 메타데이터를 보유하고 `9c810776` (`v0.8.4-1`) 이 ADR 의 commit 주장과 정확히 일치한다. ADR 결함이 아니라 근거 문서의 provenance 각주가 stale — 분석 문서 갱신 권장.
