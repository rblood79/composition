### 근본 반론 (hate)

- **load-bearing 가정**: "`label` 을 없애면 표시 계층이 번역하지 않고는 문자열을 얻을 수 없다" (`ADR:76`)
- **root**: `labelKey` 도 `string` 이라 표시 계층이 `t()` 를 빠뜨리고 `item.labelKey` 를 그대로 그려도 **타입은 통과**한다. 타입이 막는 것은 "`label` 이라는 이름이 없다" 뿐이고 "키를 번역하지 않고 그린다" 는 못 막는다 — 대안 C 대비 판별력이 ADR 주장만큼 크지 않다. 공격 축: load-bearing 사실이 거짓
- **first nail**: 표시 계층 테스트 1개 — "DOM 텍스트에 `contextMenu.` 접두 문자열이 없다" 단정. 비용 테스트 1건 vs 프로그램 Phase 6 · Gate 5
- **판정**: G1 은 카탈로그 존재만 보고 번역 여부를 안 본다. G5(Live)가 Phase 5 에서야 잡는다 → 이슈 #4 (MEDIUM)
