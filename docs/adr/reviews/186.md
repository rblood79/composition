# ADR-186 Review Log

## Round 1 — 2026-08-19 (reviewer: claude)

## ADR 리뷰 결과: ADR-186 Photoshop 기본 및 Pencil 9-zone 패널 배치 정책

### Findings

1. **HIGH — exact v2 backup만으로는 operational rollback이 성립하지 않는다.** ADR은 exact backup이 operational rollback을 가능하게 한다고 단언하고(`docs/adr/186-photoshop-default-zone-panel-placement.md:212-224`), breakdown은 v2 raw를 별도 key에 prepared/committed로 저장하는 것까지만 정의한다(`docs/adr/design/186-photoshop-default-zone-panel-placement-breakdown.md:270-278`). 하지만 현재 v2 build는 primary를 v2→v1 순으로만 해석하고 실패하면 `.v1-backup`을 복원한다(`apps/builder/src/builder/layout/panelWorkspaceLayoutV2Persistence.ts:208-247`). 새 `.v2-backup` key를 읽는 주체가 없으므로 v3 primary 이후 현재 v2 build로 code rollback하면 오래된 v1 배치 또는 default로 떨어질 수 있다. ADR-922는 이 문제를 피하려 backup 없는 v2-born record의 최소 operational rollback target을 v2-capable Phase 3 이상으로 고정했다(`docs/adr/completed/922-photoshop-style-panel-layout-coordinator.md:126-135`). ADR-186도 최소 v3-aware rollback phase, prepared→primary 성공→commit marker 실패 복구, migrated-v2/v3-born/post-migration-edit fixture를 G1/G5에 명시해야 한다.

2. **MEDIUM — focus-order 배열 방향이 migration 계약에 고정되지 않았다.** breakdown은 `floatingFocusOrder`의 topmost cluster부터 zone을 배정한다고만 한다(`docs/adr/design/186-photoshop-default-zone-panel-placement-breakdown.md:257-264`). 현재 구현은 최근 focus cluster를 배열 끝에 append하고(`apps/builder/src/builder/layout/panelWorkspaceLayoutInteraction.ts:285-288`) index가 클수록 높은 z-index를 준다(`apps/builder/src/builder/layout/PanelWorkspace.tsx:102-112`). 따라서 현 의미는 tail이 topmost다. v3 `clusterFocusOrder`도 head/tail 의미가 정의되지 않았다(`docs/adr/design/186-photoshop-default-zone-panel-placement-breakdown.md:127-132`). 배열 순회 방향과 동률 collision winner fixture를 명시하지 않으면 deterministic test가 통과해도 가장 위 cluster가 예상과 다른 zone을 가져갈 수 있다.

3. **MEDIUM — 10+ cluster fallback은 mixed-rail cluster를 결정적으로 분해할 수 없다.** 초과 cluster를 ‘해당 panel들의 기본 rail zone’에 합친다고 했지만(`docs/adr/design/186-photoshop-default-zone-panel-placement-breakdown.md:263-268`), ADR 자체가 cross-rail snap 뒤에도 `railOrder` membership을 보존하도록 요구한다(`docs/adr/186-photoshop-default-zone-panel-placement.md:90-94`). 현 snap mutation도 target cluster에 source를 삽입하면서 railOrder를 바꾸지 않는다(`apps/builder/src/builder/layout/panelWorkspaceLayoutInteraction.ts:296-345`). 따라서 하나의 v2 cluster에 left/right/bottom identity가 섞일 수 있다. 초과 cluster를 persisted `railOrder`별로 split할지, cluster 단위로 한 zone에 둘지, row/column stable order를 어떻게 합칠지 명시하고 mixed-rail 10번째 cluster 기대 JSON을 G1 fixture로 고정해야 한다.

4. **LOW — ADR 대시보드 headline이 stale이다.** 최신 업데이트는 합계 210을 선언하고(`docs/adr/README.md:5`) 현황 요약도 192+3+15=210이다(`docs/adr/README.md:242-249`). 그러나 상단 현재 현황은 여전히 194/12/209다(`docs/adr/README.md:3`).
