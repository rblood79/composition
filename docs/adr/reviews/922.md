# ADR-922 Review Log

## Round 1 — 2026-08-18 (reviewer: codex)

## ADR-922 cache-clear 초기 상태 검토

### 코드 검증

| 관찰                                                                                     | 판정     | 근거                                                                                                                                                           |
| ---------------------------------------------------------------------------------------- | -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| left Nodes/right Properties가 cache-clear 직후 anchored frame으로 보이고 Canvas가 축소됨 | VERIFIED | `DEFAULT_PANEL_LAYOUT`가 `activeLeftPanels:[nodes]`, `activeRightPanels:[properties]`를 정의하고 solver가 anchored cluster+rail을 `occupiedInsets`로 반영한다. |
| bottom Monitor toggle 영역이 보이고 main height가 rail만큼 줄어듦                        | VERIFIED | Monitor는 default bottom rail에 등록되며, railOrder가 비어 있지 않으면 bottom rail 48px을 점유한다.                                                            |
| panel background가 보임                                                                  | VERIFIED | workspace shell이 frame에 `bg-overlay`, content에 `bg-inset`을 명시한다.                                                                                       |

### ADR 대조

ADR-922 Hard Constraint 4는 anchored cluster와 activity rail의 occupiedInsets를 actual Grid/Flex main track에 정확히 한 번 반영하도록 요구한다. breakdown browser flow도 default Nodes/Properties 표시와 shell inset 적용을 명시한다. 따라서 Canvas가 panel/rail 영역만큼 축소되는 것은 구현 누락이 아니라 ADR이 선택한 동작이다.

### 발견 사항

- MEDIUM — cache-clear 신규 workspace에서 초기 frame을 열어 둘지, rail만 보일지의 제품 정책은 Decision/Hard Constraint로 명시되지 않았다. 현 구현은 legacy `DEFAULT_PANEL_LAYOUT`를 계승해 Nodes/Properties를 연다. 사용자가 기대하는 Photoshop식 rail-only launch는 이 정책을 변경해야 하며, 단순 CSS 수리가 아니다.

### 종합 판정

- 코드 정합: VERIFIED
- ADR 누락 위험: MEDIUM 1건 — fresh-cache startup policy
- 결론: 현재 관찰은 ADR-922 위반이 아니다. 초기 정책을 rail-only launch로 바꾸려면 ADR amendment와 default layout/rail occupancy 결정을 별도로 확정해야 한다.
