# ADR-295 Review Log

## Round 1 — 2026-10-30 (reviewer: codex)

판정: **수정 필요 — HIGH 2 / MEDIUM 1 / pending 3**. 대상은 Proposed 설계이며 제품 구현 결함 판독이 아니다. HEAD `2c2ce9baa` 및 작업 트리의 ADR·breakdown을 대조했다.

1. **HIGH — 속성 이름만으로 scale 여부를 정하면 S2 상대 치수를 재현할 수 없다.**
   - 위치: `docs/adr/295-d3-token-values-s2-style-macro-scale.md:139-152`, breakdown `:100-114`.
   - 설치본 1.8.1 `apps/builder/node_modules/@react-spectrum/s2/style/spectrum-theme.ts:416-447`의 spacing/padding은 고정 숫자뿐 아니라 `fontRelative`, `pill`, `edge-to-text`를 포함한다. `src/style-utils.ts:291-324`의 Button control은 pill padding과 minHeight를 사용하고 `src/Switch.tsx:91`의 gap은 text-to-control이다. 또한 `spectrum-theme.ts:871-886`에는 width/maxWidth/maxHeight의 scalable sizing이 있고 `:500-505,954-959`의 일반 inset은 고정 px 표를 읽는다. ADR의 축 allowlist와 실제 분류가 다르다.
   - 재현 입력 → 결과: 사용자 결정 1에서 padding 정렬을 선택한 Button M을 desktop→touch로 전환. S2 minHeight 32→40에 따라 paddingX 16→20이어야 하지만 제안된 px 고정 방식은 16에 머물러 양쪽 padding 합계가 8px 부족하다. Switch M의 gap도 font 14→17에서 10→12.142857px이지만 ADR은 10을 유지한다. 두 leg가 같은 잘못된 값을 받으면 G2 대칭은 통과할 수 있다.
   - 수정 방향: 축 allowlist 대신 설치본에서 나온 값의 의미를 fixed / system-scale / font-relative / control-relative로 구분하고 한 resolver에서 평가한다. 컴포넌트별 내부 치수도 G0/G4에 포함하고 Button padding·Switch gap/track·일반 inset의 desktop/touch 결과를 독립 S2 oracle과 비교한다. 사용자 선택으로 정렬을 제외할 축은 명시적 예외로 적고 전체 S2 일치 주장을 제한한다.

2. **HIGH — radius seed만 바꾸면 활성 테마 preset이 이전 값으로 덮어쓴다.**
   - 위치: `docs/adr/design/295-d3-token-values-s2-alignment-breakdown.md:92`, ADR `:171`.
   - 실제 경로: `packages/shared/src/catalog/runtime/resolveThemeSnapshot.ts:179-182`는 SEED_RADIUS 뒤에 resolveRadiusTokens(preset.radiusScale)를 spread한다. `radiusScaleToSkia.ts:35-57`의 별도 RADIUS_BASE_PX는 md 6 / lg 8 / xl 12 / 2xl 16이다.
   - 재현 입력 → 결과: 명시 radius 델타가 없는 radiusScale=md 테마에서 제안 seed 8 / 10 / 16 / 24를 넣어도 최종 맵은 6 / 8 / 12 / 16이다. 3xl·4xl을 seed에서 지워도 이 경로가 다시 추가한다. Canvas와 DOM이 모두 구값을 받아 G2는 통과하고 seed만 검사하는 G4도 실제 설치 오류를 놓친다.
   - 수정 방향: RADIUS_BASE_PX와 seed를 같은 새 표에서 파생하고 preset 배율→명시 델타 우선순위를 유지한다. G4는 seed뿐 아니라 활성 테마의 최종 snapshot과 CSS 변수, 테마 전환 및 reset/null 경로를 확인하도록 수정한다.

3. **MEDIUM — 생성 CSS를 공유하므로 shared-tokens.css 동결만으로 Builder chrome을 보존할 수 없다.**
   - 위치: `docs/adr/295-d3-token-values-s2-style-macro-scale.md:168-173`, breakdown `:103,111`.
   - 실제 경로: `apps/builder/src/main.tsx:43`이 `builder-components.css`를 싣고, 이 시트 `:22-38`은 generated ToggleButton/Input/TextField/Select/ComboBox 등을 직접 import한다. Preview 전용 CSS가 아니다.
