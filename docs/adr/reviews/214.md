# ADR-214 Review Log

## Round 1 — 2026-09-11 (reviewer: codex)

### 구조 판정

- **Context: PASS (확신 HIGH)** — 소유자 부재, 소비처 부재, D2 범위와 Hard Constraint를 명시한다 (`docs/adr/214-variables-owner-model-runtime-state.md:11-37`).
- **Alternatives / 4축 / Threshold: PASS (확신 HIGH)** — A~D가 모델·저장·소비·표면과 기술·운영·마이그레이션·유지보수 위험을 비교한다 (`docs/adr/214-variables-owner-model-runtime-state.md:39-89`).
- **Decision / Risks / Gates: PARTIAL (확신 HIGH)** — 선택·기각 근거와 Phase 분리는 명확하지만 invalidation, copy, persist, 성능, migration 계약이 닫히지 않았다 (`docs/adr/214-variables-owner-model-runtime-state.md:91-136`; `docs/adr/design/214-variables-owner-model-runtime-state-breakdown.md:55-128`).

### 코드 정합

- **VERIFIED**: 현재 `Variable`에는 component owner id가 없고 (`apps/builder/src/types/builder/data.types.ts:278-326`), 생성값은 project id와 name-keyed Map에 저장된다 (`apps/builder/src/builder/stores/utils/dataActions.ts:697-728`).
- **VERIFIED**: preview store는 global 기본값과 app/page/component 상태 API를 제공하지만 (`apps/builder/src/preview/store/runtimeStore.ts:605-721`), 기존 EventEngine 값의 실제 소비 호출은 없었다 (`apps/builder/src/preview/App.tsx:1390-1393`).
- **VERIFIED**: interaction union과 dispatcher에는 navigate/toast/capability만 있고 setState는 없다 (`packages/shared/src/interactions/interactionRule.types.ts:17-47`; `packages/shared/src/interactions/dispatcher.ts:133-187`).
- **PARTIAL**: shared runtime·template·publish 배선은 신규 계획이므로 자동 적용은 현재 코드로 확증할 수 없다.
- **UNVERIFIED**: 노드 필드의 복제·붙여넣기 자동 보존 주장은 adapter와 copy read model에서 state가 사라져 성립하지 않는다 (`apps/builder/src/builder/stores/canonical/canonicalElementsView.ts:167-208`; `apps/builder/src/builder/workspace/canvas/actions/canvasActions.ts:45-101`).

### 중요 누락과 위험

1. **HIGH — Canvas state-only 편집 invalidation 모순**: `defaultValue` 변경은 시각 변경이나 projection signature에 `state`가 없고 (`apps/builder/src/builder/workspace/canvas/scene/buildSceneSnapshot.ts:58-75`), G1은 sceneVersion 불변을 요구한다.
2. **MEDIUM — lifecycle 자동 보존 근거 부재**: duplicate/paste가 state 없는 Element map을 거치고 id remap은 요소 id·부모만 다룬다 (`apps/builder/src/builder/utils/multiElementCopy.ts:342-445`).
3. **MEDIUM — 성능 Gate 판정 불가**: G3에 fixture 출처, 불리 케이스, 변경 전 A/B, 허용 수치, 측정 조건이 없다 (`.claude/rules/measurement-validity.md:15-25,56-59`).
4. **MEDIUM — persist 프로젝트 격리 누락**: 현 저장은 단일 key에 변수 이름으로 값을 저장·복원한다 (`apps/builder/src/builder/stores/data.ts:87-120,188-223`).
5. **MEDIUM — migration 비용 미수식화**: component 승격의 분모·표본·수치 threshold가 없다 (`docs/adr/214-variables-owner-model-runtime-state.md:117-129`; `.claude/rules/adr-writing.md:227-250`).

### HATE

부하를 지탱하는 가정은 “state를 sceneVersion에서 제외해도 Canvas 기본값이 즉시 갱신된다”이며 **거짓**이다. 가장 싼 첫 못은 `Hello {{ userName }}`의 defaultValue를 guest→Ana로 바꾸어 Canvas 즉시 갱신과 비의존 노드 비갱신을 확인하는 fixture다. G1과 G2는 이 편집 경로를 덮지 못한다.

### PRISM

| 렌즈                      | 판정 | 핵심 근거                                       |
| ------------------------- | ---- | ----------------------------------------------- |
| state/render invalidation | FAIL | state-only 시각 변경의 갱신 owner가 없다        |
| lifecycle/SSOT            | FAIL | canonical→legacy copy 경계에서 state가 누락된다 |
| measurement integrity     | FAIL | G3에 A/B·threshold·측정 조건이 없다             |
| compatibility/isolation   | FAIL | persist namespace와 migration 분기점이 없다     |

수렴은 **다른 이유로 일치**이며 해소 질문은 없다.

### 종합 권고

**수정 후 재리뷰**. state-only Canvas 갱신 owner와 Gate, clone/paste/origin-instance remap, project-scoped persist와 전환 검증, 수치화된 G3, component migration threshold를 ADR과 breakdown에 반영해야 한다.
