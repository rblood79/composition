# ADR-236 Review Log

## Round 1 — 2026-09-24 (reviewer: claude)

## 종합 판정

수정 후 재검토. HIGH 1 · MEDIUM 4 · LOW 1.

대안 D (shared 특성 표 + 술어 모듈 + 강제 통합) 의 방향과 대안 비교 · 4축 평가 · Risk/Gate 대응 구조는 타당하다. 막는 문제는 Phase 3 의 강제 지점 정의 (H1) 하나다 — 현재 문구대로면 ADR-184 러너 밖의 기존 쓰기 경로가 빠져 '한 지점' 이 성립하지 않는다.

## 이슈

- **H1** store 한 지점 강제 ↔ 러너 allowlist 구조 불일치 → 강제 지점을 store 액션 진입부로 재정의 + 구조 변경 액션 목록 ratchet (권장), 또는 러너 이관 (ADR-184 범위 변경 = 결정 지점).
- **M1** 파생 대상과 '렌더 분기 제외' 범위 규칙 충돌 → 멤버십/렌더 동작 판정 기준 1줄 + skia 소비처 픽셀 무변경 확인.
- **M2** Context 실측 정정 — Components 페이지 직접 비교 0 (헬퍼 3변형 · 호출 21), body 는 로컬 헬퍼 8+.
- **M3** G4 지표를 canX 자체 비용으로.
- **M4** 특성 표 위치 사용자 confirm 기록 (Accepted 전제).
- **L1** R2 예시 갱신.
