### Findings

#### [HIGH] canonical write target과 renderer projection identity가 하나의 targetId로 축약되어 ref/instance descendant 정합을 보장할 수 없음

- 원문 분류: render-target-identity-gap
- Evidence: breakdown:151-213,500-567; apps/builder/src/resolvers/canonical/index.ts:162-220,250-284; apps/builder/src/adapters/canonical/canonicalRefResolution.ts:523-619,670-716
- Root cause: session은 targetIds+pathKeys를 캡처하지만 descriptor와 Preview message는 targetId만 전달한다. 동시에 Preview resolver는 ref root에 instance id를 유지하고 origin child id를 재사용하는 반면, Skia canonical ref tree는 descendant를 `${refId}/${path}` synthetic id로 materialize한다. canonical write identity, semantic descendant path, renderer-space projection identity가 분리되어 있지 않다.
- Impact: instance descendant override 또는 reusable origin 변경에서 Skia와 Preview가 서로 다른 노드를 patch하거나 한쪽만 갱신할 수 있다. 현재 G4의 `instance/ref target` 한 줄로는 origin root, origin descendant, per-instance descendant 세 경우를 구분하지 못한다.
- Required revision: shared `PresentationTargetRef` 계약으로 canonical target id + descendant path + renderer projection resolution을 명시하고, `affectedIds`의 k를 render-space affected node 수로 정의한다. protocol이 path/target identity를 보존하고, 양 renderer가 동일 fixture로 origin root/descendant 및 instance override fan-out을 검증해야 한다.
- Outcome: fixed — semantic `EditorPresentationTargetRef`, renderer-local projection index,
  origin/ref fan-out matrix와 G4-A로 보완

#### [HIGH] Preview finish가 canonical document 수신보다 먼저 overlay를 제거할 수 있어 final-frame 원자성이 없음

- 원문 분류: terminal-handoff-ordering-gap
- Evidence: ADR:130-132,245-247; breakdown:318-329,515-546; apps/builder/src/builder/hooks/useIframeMessenger.ts:1082-1106; apps/builder/src/preview/messaging/messageHandler.ts:279-283
- Root cause: finish message에는 session revision만 있고 committed canonical document revision/ack가 없다. Preview는 finish 수신 즉시 overlay를 제거하지만 기존 canonical full-document sync는 React effect 뒤 `scheduleFrameOrTimeout`으로 지연된다. patch stream tombstone은 canonical document stream과의 순서를 보장하지 않는다.
- Impact: finish가 먼저 도착하면 Preview가 이전 canonical 색상을 한 frame 이상 다시 그릴 수 있으며, 이는 HC9의 종료 후 차이 0과 Decision의 final frame flicker 방지 목적을 직접 위반한다.
- Required revision: finish에 내부 `committedDocumentRevision`을 싣고 Preview가 해당 canonical revision을 수신할 때까지 final overlay를 유지하거나, authoritative final descriptor를 포함한 atomic handoff/ack 계약을 정의한다. G4에 finish-before-document, document-before-finish, duplicate/out-of-order 두 stream 조합을 추가한다.
- Outcome: fixed — `committedDocumentRevision`, final mutation latch, canonical replace와
  overlay retirement의 atomic Zustand update, G4-B로 보완

#### [MEDIUM] classifier SSOT 보완이 5-symbol 체인을 완전히 포함하지 않고 영구 drift 방지도 없음

- Evidence: ADR:227-236; breakdown:230-254; apps/builder/src/builder/stores/utils/elementUpdate.ts:46-119,168-172; apps/builder/src/builder/stores/utils/layoutInvalidation.ts:1-10; apps/builder/src/builder/workspace/canvas/scene/layoutCache.ts:78-85,171-178
- Root cause: 수정본은 `LAYOUT_AFFECTING_PROP_KEYS`, `NON_LAYOUT_PROPS_UPDATE`, `LAYOUT_STYLE_KEYS`, `LAYOUT_PROP_KEYS`만 열거해 상속 layout 축인 `INHERITED_LAYOUT_PROPS_UPDATE`를 누락했다. 또한 `classifyEditorMutation`을 유일 SSOT로 선언하면서 기존 배열을 계속 독립 소유하게 하고 G2의 1회 대조만 규정해 이후 drift를 구조적으로 막지 못한다.
- Impact: typography/inherited style은 drag 중 신규 classifier와 finish 후 기존 layout/cache 체인이 다르게 판정될 수 있다.
- Required revision: neutral shared property-effect registry에서 classifier와 기존 5-symbol 소비자를 derive하거나, 최소한 5개 심볼 전수 parity를 영구 정적 테스트/G7 gate로 고정한다.
- Outcome: fixed — neutral effect registry에서 5-symbol view 전부 파생하고 G2 baseline
  parity + G7 독립 literal 정적 guard로 보완
