# ADR-249 Review Log

## Round 1 — 2026-09-29 (reviewer: codex)

판정: HIGH 2 · MEDIUM 2, 현 설계대로 착수 전 수리 필요. 제품 코드와 ADR 상태는 변경하지 않았다.

1. HIGH — Events 패널만 scope 후보로 남긴 뒤 메뉴에서 복사를 누르면 `getScopedHandler`가 Events placeholder를 실행해 선택한 캔버스 요소가 복사되지 않는다. 메뉴 클릭 중 `activeScope`를 무시한 명시적 캔버스 동작 선택 또는 메뉴 명령별 대상 scope 계약을 정하고 실제 메뉴 클릭을 G1/G3에서 확인해야 한다.
2. HIGH — Styles 패널을 닫고 선택 요소가 남은 상태에서도 상시 `CanvasSelectionShortcutsHost`가 `copyStyles`/`pasteStyles`를 등록한다. `등록 + precondition`은 이를 활성으로 표시해 문서의 G1 기대값과 어긋난다. 패널 visibility를 판정에 포함하거나 닫힌 상태에도 활성이라는 정책과 게이트를 함께 고쳐야 한다.
3. MEDIUM — 선택이 없으면 `handleZoomToSelection`은 bounds 없음으로 바로 return하지만 `COMMAND_META.zoomToSelection`에는 precondition이 없다. `AgentReadModel`만으로 bounds를 얻을 수 없으므로 캔버스가 제공하는 실행 가능 상태를 추가하거나 별도 비활성 판정을 정의해야 한다.
4. MEDIUM — V4 레이아웃의 `railOrder.bottom`에 패널이 놓일 수 있는데 설계 메뉴는 왼쪽/오른쪽만 둔다. bottom 패널을 포함할 구역과 G0/G3 이동 시나리오를 명시해야 한다.

검증: ADR 본문·breakdown, 명령 레지스트리/핸들러, scope, 패널 workspace, snapshot 경로를 정적으로 대조했다. 테스트·실제 Builder 클릭·번들 측정은 실행하지 않아 런타임 결과와 G0~G3는 UNVERIFIED다. G3의 명령 5/패널 3 표기는 breakdown의 작업 공간 4와 불일치하므로 gate 문안도 동기화가 필요하다.

## Round 2 — 2026-09-29 (reviewer: codex)

수리 확인 판정: 1차 HIGH 2 · MEDIUM 2의 실패 조건과 대응 방향은 본문·breakdown·G0/G1/G3에 반영됐다. 최신 리뷰에서 HIGH 0, MEDIUM 2 pending. 제품 코드와 ADR 상태는 변경하지 않았다.

1. MEDIUM — 선택 없음 → 메뉴의 ‘선택에 맞춤’ 비활성을 만들려면 BuilderCanvas가 등록한 `canRun`이 commandRegistry까지 가야 한다. 현행 useKeyboardShortcutsRegistry는 KeyboardShortcut에서 id/handler/scope/priority/allowInInput/disabled만 복사한다. breakdown의 파일 경계는 commandRegistry와 BuilderCanvas만 수정 대상으로 적어 hook과 KeyboardShortcut 타입이 빠졌다. 이대로면 `canRun`이 유실되어 선택이 없어도 명령이 활성이다. hook의 타입·게시 경로를 변경 범위에 넣고 `canRun=false` 등록에서 메뉴 비활성을 검증해야 한다.
2. MEDIUM — Styles를 닫으면 스타일 복사가 비활성이어야 한다는 정책은 명확해졌지만, 소속 패널을 `PANEL_SCOPE_MAP`의 역으로 구한다는 구현 경로는 현재 불가능하다. 상수가 useActiveScope.ts의 비공개 값이며 해당 파일은 읽기만 대상으로 적혀 있다. 이 매핑을 공용으로 추출·export하거나 `panel:*` scope의 suffix를 PanelRegistry id로 검증해 파생하도록 정해야 한다.

H1의 명시적 canvas scope 실행 인자와 Elements 수 결과 게이트, M4의 bottom 구역과 G0/G3는 설계상 확인됐다. 정적 문서·코드 대조만 수행했다. 새 코드가 없으므로 G0~G3와 실제 Builder 동작은 UNVERIFIED다.
