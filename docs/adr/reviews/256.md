## round 1 — 2026-10-07 (사용자가 붙여 넣은 판독 · 실행자 코드 확인)

판독 원문은 사용자가 대화에 붙여 넣었다 (작성 주체 미표기). 실행자가 7건 전부 코드 · 레퍼런스로 확인했다 — Text binding 의 `slot` 부재 (`Text.binding.ts:29-40`) · Preview Text 의 context 없는 span (`domBinding.tsx:479-494`) · 설치 RAC 1.21.0 의 `CalendarCell` · `DateSegment` export · ProgressBar 예제의 `percentage` · `valueText` (`ProgressBar.md:26-33`) · Checkbox 예제의 `isIndeterminate` 분기.

### 반영 (같은 날)

- **h1** → Decision 11 · G5: 구조 비교의 축 (태그 · 부모-자식 · 형제 순서 · 텍스트 · `slot` · role/aria · aria 연결) 과 제외 항목 (자동 id · `data-catalog-id` · `data-*` · class · inline style). 시각 비교 (G3 수치) 와 별개로 둘 다 통과. S2 전용은 `@react-spectrum/s2` 테스트 devDependency 마운트가 기준값.
- **h2** → Decision 4 둘째 항: 「주는 slot 이름 × 받는 부품 type」 표 · 가장 가까운 context 조상의 이름만 slot 선택 UI 에 · Text · Icon · Button · Heading · Image · Avatar binding 의 `slot` · Preview 는 slot 을 주는 부모 안에서 RAC Text. 새 위험 R10 (slot 없는 RAC Text throw) · G2 에 slot 지정 · 제거 · 이동 시험. breakdown Phase 1 에 포함.
- **m1** → Decision 7: 주체 = 가장 가까운 RAC 상태 조상 (Group · Frame 통과) · 조건 고정 목록 11 · 형식 `{ all: [isX | { not: isX }] }` ≤ 3 · 노드 간 우선순위 없음 (Checkbox 체크 · 가로선은 노드 둘) · 거짓이면 DOM · 레이아웃 없음 · Canvas 는 displayState + 파생 값, hover 류는 Preview 만.
- **h3** → 새 Decision 12: `{key}` 바인딩 출처를 상태 주체의 render props 로 넓힘 (`{percentage}` · `{valueText}` · `{formattedDate}` …), Canvas 는 파생 값. breakdown Phase 4 · 7 · 예제 14.
- **m2** → 새 Decision 13: 반복 부품 template (CalendarCell · 요일 칸 · DateSegment) — Preview 는 children 함수가 template 을 항목마다, Canvas 는 grid primitive 가 template 모양을 읽음. 실패 시 명시 제한. 새 위험 R11. breakdown §2-2 · Phase 9 · 예제 15.
- **m3** → Decision 5: 존재 + context 관계가 계약. 같은 context 안 재배치 · wrapper · 동등 원본 교체 허용, 결과 트리가 RAC 관계를 깰 때만 거부. G2 에 재배치 · wrapper 시험.
- **m4** → Decision 11 · G0 ⑥ ⑧ ⑨ · breakdown §4: 예제마다 코드 · 조회일 · RAC 버전 · 비교 상태 · 조립 절차 · 저장 재열기를 Phase 0 evidence 에 고정. 예제에 없는 family 의 G2 연결 표. R7 수정 — 파생 값 있는 상태는 page instance 의 Canvas↔Preview 로 검증, Components page 는 보조.
