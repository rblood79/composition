**FieldError 같은 상태 짝 (round 31 r31m1 재판정)** — 종전 행은 Canvas 를 기본 상태 (factory `display:none`) 로, DOM 을 invalid 상태 (`isInvalid:true` + `errorMessage`) 로 재서 "일치" 로 두었다 (상태가 다른 두 값을 설명문으로 제외). 재측정은 두 상태를 양쪽에서 각각 잰다 (`fieldErrorStates`, 테스트 3번째 `it`):

| 상태                                             | Canvas 경계 (팔레트 TextField 트리, parent props 만 변경)                           | DOM (shared `TextField` live)                | 판정                                                                                       |
| ------------------------------------------------ | ----------------------------------------------------------------------------------- | -------------------------------------------- | ------------------------------------------------------------------------------------------ |
| 기본 (`isInvalid:false` · `errorMessage: ""`)    | `none` (factory inline `display:none`, `FormComponents.ts` TextField 정의)          | (없음) — RAC `FieldError` 가 렌더하지 않음   | 양쪽 상자 없음 = 일치                                                                      |
| invalid (`isInvalid:true` · `errorMessage` 있음) | `none` — Canvas 에 `isInvalid` 를 읽는 코드가 0 (grep), 자식 inline style 이 그대로 | `span:block` (flex column 자식이라 blockify) | **갈림** — display 값이 아니라 parent 상태 prop → 자식 가시성 투영 부재 (`투영필요(후속)`) |

원복 (g) 가 보이듯 자식의 inline `display:none` 을 걷으면 Canvas 는 catalog 기본 `inline-flex` 를 보내고 (flex column 부모라 엔진 blockify → flex) DOM 은 `block` — outer 는 양쪽 block-level 로 같다. 즉 남는 격차는 **상태 → 가시성** 이며 display 어휘 (ADR-923 범위) 가 아니다. 수리는 TagGroup 슬롯 자식 `isTagGroupSlotChildVisible` (r21m1) 과 같은 형태 — field 가족 5 (TextField · TextArea · NumberField · DateField · TimeField, `FIELD_VISIBLE_CHILD_TAGS`) 의 FieldError 가시성을 parent `isInvalid`/`errorMessage` 로 정하고 텍스트도 parent `errorMessage` 를 투영 (propagation 규칙 부재) — 별도 commit (§9 · breakdown Phase 5 후속). 분포는 일치 7 → 6, 투영필요(후속) 1 (33 유지); 테스트가 7 범주 분포 전체를 단언한다.
