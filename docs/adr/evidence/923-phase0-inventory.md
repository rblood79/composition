## §A. Canvas 전용 display override 전수 (HC2 · G4 후반 입력)

> **round 4 (Codex r4m1) 정정 2026-08-31**: 초판은 (ii) 를 "DOM 이 inline-\* 인 rule" 로만 세고, base 셀렉터 매칭이 `.react-aria-Skeleton.button` 같은 compound 변형까지 base 로 잡았다. HC2 문면은 **정확한 display 값** 비교이므로 전수를 정확값 기준으로 다시 세고 base 셀렉터를 `.react-aria-{Rule}` 단독으로 좁혔다 — 정확값 불일치 5 → **13** (Codex 가 지적한 8 = ColorPicker · ColorSlider · ColorSwatchPicker · FileTrigger · GridList · Skeleton · Tag · TagList 전부 성립). 초판 (ii-a) 17 중 13 은 일치, 3 은 DOM 충돌, 1(FileTrigger) 은 (ii-s) 로 재분류.

### A-1. 방법

- **catalog**: `packages/shared/src/catalog/generated/componentRulesTable.ts:17` `COMPONENT_RULES_TABLE` 의 객체 키 **123** (`body` · `frame` · `Slot` · `Group` 포함). `tsx` import 로 `containerStyles.display`(top-level) · `structure.containerStyles.display` · `structure.composition.containerStyles.display` · `structure.composition.layout` 을 추출. top-level display 보유 16, top-level `containerStyles` 는 있으나 display 키가 없는 rule 9 (body · Description · GridList · Heading · Paragraph · Column · Cell · Table · Text).
- **Canvas 실효 display** (자기 style 경로): `apps/builder/src/builder/workspace/canvas/layout/engines/implicitStyles.ts:291 resolveContainerStylesFallback` — top-level `rule.containerStyles` 가 있으면 그것을 **통째로 대체** (`:341-347` 주석 "top-level 은 override 가 아니라 대체"; display 키가 없으면 structure 의 display 도 무시된다 — Text/GridList), 없으면 `packages/shared/src/catalog/resolvers/resolveCatalogContainer.ts:77 resolveCatalogContainerBase` (layout 토큰 `LAYOUT_TOKEN_STYLES` → `structure.containerStyles` → `structure.composition.containerStyles`, last-wins). 어느 쪽에도 display 가 없으면 `getElementDisplay` 기본값 (`INLINE_BLOCK_TAGS` → `inline-block`, 그 외 `block`). **HC2 가 말하는 "catalog `containerStyles.display`" 는 top-level 16건이지만 Canvas 가 실제 읽는 display 는 이 전체 경로다** — 표의 "Canvas 실효" 열이 그 값.
- **DOM CSS**: `packages/shared/src/components/styles/**/*.css` 146 파일에서 `display:` 선언 **376** 건을 셀렉터·file:line 과 함께 파싱. base = 마지막 compound 가 **정확히 `.react-aria-{Rule}` 하나** (추가 class · 속성 · 의사 선택자 없음, 조상 문맥 없음). compound 변형(`.react-aria-Skeleton.button`) · 문맥(`.react-aria-Calendar .react-aria-Button`) · 상태(`[data-…]`, `:hover`) 선언은 base 가 아니다. **캐스케이드 결과가 아니라 선언 기준** — 한 파일 안에서 같은 셀렉터가 두 번 display 를 내면 둘 다 인용하고 파일 실효값은 뒤(last-wins) 로 본다 (generated CSS 는 "Base styles — archetype" 블록과 "Container styles" 블록이 각각 display 를 낸다 — 예 `generated/Card.css:11 inline-flex` → `:23 flex`). live 파일 간 실효값이 다르면 "DOM 충돌".
- **live / dead**: import 그래프 = `styles/index.css` `@import` + 컴포넌트 tsx 의 `import "./styles/X.css"` + css 간 `@import`. 어디서도 import 되지 않는 **27 파일**은 `[dead]` 표기 (A-4) 하고 실효값 산정에서 제외.
- **판정 (정확값)**: 일치 · 일치(기본값 — catalog display 없음이지만 Canvas 기본 block = DOM block) · **(i)** top override ≠ DOM · **(iii)** catalog 만 inline-\* · **(ii-s)** structure 층 display ≠ DOM · **(ii-g)** catalog display 없음 → Canvas 기본값 ≠ DOM · DOM 충돌 · DOM 선언 없음 (catalog 있음) · 둘 다 없음. "outer 동일" 열 = line box 참여(outer) 는 같고 inner 만 다른가 (✓) / outer 가 다른가 (✗).
