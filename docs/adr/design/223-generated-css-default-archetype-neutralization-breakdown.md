# ADR-223 구현 설계: 생성 CSS archetype 미지정 기본값 중립화

정본: [ADR-223](../223-generated-css-default-archetype-neutralization.md)

작성일: 2026-09-18. 코드 사실은 이 날짜의 main (`73ce6fc3e`) 실측이다 — 착수 시 Phase 0 에서 재실측한다.

## 1. 전제 lock-in

- base / 응용: 이 ADR 은 생성기 기본값 하나 (`DEFAULT_BASE_STYLES`) 를 바꾸는 base 결정이다. ADR-171 (catalog layout 전달) · ADR-907 Layer B (container layout = props.style) · 944fc78d6 (Section·Nav `container`) 는 선행이고, 이 ADR 은 그 셋의 전제를 바꾸지 않는다 — DOM 전용 채널을 **줄이는** 것뿐이다.
- schema: catalog `structure.archetype` 문자열 값의 의미가 바뀐다 (`"default"` = 미지정 → 중립 상자). Pagination 은 기존 `structure.containerStyles`, Card·Tab interaction 은 기존 `structure.composition.rootSelectors["&"]` 를 사용하므로 문서 schema · PropContract · D2와 generator API는 무변경이다.
- 의존 방향: Skia 는 archetype base 를 읽지 않는다 (§2 표 F5). 따라서 "DOM 기본값을 Skia 쪽으로 맞춘다" 가 유일한 방향이고, 반대 (Skia 가 버튼 어법을 읽는다) 는 ADR 본문 대안 D 로 기각.
- fork 아님: 신규 ADR 하나. sub-phase 분할 없음 (Phase 3개, 파일 ≤ 15).

## 5. 범위 밖 (이 ADR 이 하지 않는 것)

- Nav 의 `display/flexDirection/alignItems` 를 catalog `structure.containerStyles` 로 올리는 것 — ADR-907 Layer B ("container layout = props.style") 경계 판정이 먼저다. 별도 판정.
- 미로드 생성 CSS 4건 (AvatarGroup · ButtonGroup · CardView · Body) 의 로드 여부 — ADR-923 인벤토리 판정 유지.
- `archetype` 을 필수 타입으로 바꾸는 것 (본문 대안 C) — 28 entry 직접 편집 + 타입 변경. G4 ratchet 이 같은 효과를 신규 entry 에 한정해 준다.
