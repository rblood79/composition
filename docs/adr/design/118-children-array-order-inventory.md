## Current Implementation Snapshot

- G0/G1/G2/G3/G4/G5/G6: complete by code/docs gate.
- Skia canvas drag/drop pointerup/drop final commit calls `moveElementCanonicalPrimary`, which
  splices the active canonical parent `children[]` first and derives legacy
  `parent_id`/`order_num` rows from export mirror.
- Structural-only `updateElement`/`batchUpdateElements` payloads route through
  `applyElementOrderCanonicalPrimary`, so `parent_id`/`order_num` legacy rows are treated as
  transient canonical move intent instead of final ordering storage.
- `reorderElements`/`batchUpdateElementOrders` are legacy mirror repair paths; they do not sort
  canonical source order by stale `order_num`.
- PageTree DnD uses update-rank/source order to materialize canonical page preorder. Page/root,
  LayerTree, Skia render/hit-test/layout, Preview/Publish, and component/ref materialization no
  longer use `order_num` as a primary structural ordering key.

## Phase 6 Allowlist

Allowed after final cutover:

- Canonical/export/import adapters that derive legacy `order_num` from `children[]`.
- DB/API compatibility fields and migration fixtures.
- Collection data ordering that is not represented by canonical structural children.
- Tests that explicitly assert legacy mirror payloads.
- IndexedDB legacy `elements` hydrate sort before canonical/source-order projection.
- Table structural bucket sorting and `sortElementsByOrderThenSource` legacy helper itself.

Disallowed after final cutover:

- LayerTree/PageTree primary sibling sort by `order_num`.
- Skia render/hit-test/layout order by `order_num`.
- Drag/drop write path that persists `order_num` before canonical child splice.
- Component ref/slot descendant order that replaces children by same `ref` instead of child id.

G0 passed for Phase 1 entry because the remaining `order_num`/`childrenMap` call sites were bucketed.
G6 passes for closure because the remaining non-test sort/order hits are mapped to adapter/import/export,
IndexedDB hydrate, Table/collection data, legacy helper, or compatibility bridge buckets; structural runtime
read/write paths no longer use `order_num` as the primary ordering source.
