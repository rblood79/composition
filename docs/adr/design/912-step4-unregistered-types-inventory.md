## 4분류 + step 4 차단 판정

### A. color (7) — scope 외 (touch 안 함)

`ColorArea` / `ColorPicker` / `ColorSlider` / `ColorSwatch` / `ColorSwatchPicker` / `ColorWheel` / `TailSwatch`

- **판정**: 사용자 scope 외 ("color 는 패스해", 2026-06-04). ADR-912 catalog 발효 대상 아님.
- **step 4 영향**: color spec 은 단계 5 본체 삭제 대상에서 **제외**. 별도 ADR/작업 영역. step 4 spec 삭제 시 `*.spec.ts` glob 에서 color 7 은 보존.

### C. legacy / native (11) — 유지·제거 정책 결정

`Body` / `Code` / `Field` / `Group` / `Heading` / `Kbd` / `List` / `Nav` / `Paragraph` / `Section` / `Text`

- **성격**: HTML 의미 태그(Body/Section/Nav/List/Heading/Paragraph/Code/Kbd) + RAC semantic(Group/Field) + TEXT_LEAF(Text).
- **판정**: 대부분 TEXT_LEAF 또는 container shell. `Text`/`Heading`/`Paragraph`/`Code`/`Kbd` 는 텍스트 측정 source(extractSpecTextStyle fallback) — step 2 의 "catalog 미등록 TEXT_LEAF render.shapes 측정 유지" 영역. `Body`/`Section`/`Nav`/`List`/`Group`/`Field` 는 container shell.
- **step 4 정책**: native 등록(div-like) 또는 TEXT_LEAF generic 전환 후 삭제. 현재는 fallback 유지. **별도 결정 필요** — 의미 태그는 ADR-130 frame canonical vocabulary 와 경계 점검(Group 은 D1 ARIA semantic 보존 영역).

## step 4 진입 차단 게이트 (no-go 해소 조건)

step 4 (spec 124+ 물리 삭제) 진입 전 다음 **모두 충족** 필요:

1. **[fallback 의존] value-fill 경로 대체** — **2/6 완료 (2026-06-04)**: escape 키 2개(`value_fill_bar` append / `value_fill_arc` replace) 인프라 land. **escape 로 완결된 Track sub-part 2개**: ProgressBarTrack(`f15408f29`) + MeterTrack(`24fd76172`) — DOM no-op + 자식 없음(`_hasChildren=false`)이라 escape 정상. **잔여 4개는 신규 구현 단계로 분리(선행-2b, kill criteria 발동)**: SliderTrack(SliderThumb 자식 → `_hasChildren=true` → escape `[]` 반환 + thumb 직접 그림) / ProgressCircle·ProgressBar·Meter(DOM standalone → `cutover:"catalog"` 시 DOM generic 발효로 RAC 시각 소실, DOM internal renderer wrapper 부재). **DisclosureContent 는 본 게이트에서 제외(2026-06-04 실측 = value 없는 text leaf → 게이트 #3 흡수 검증으로 이동).**
2. **[catalog 등록 후보] ~9 type 등록**: D그룹 A(Avatar 등) PrimitiveBinding 작성 + 등록 → fallback 탈출.
3. **[흡수됨] 검증 — 선행-3 완료 (2026-06-04), 전제 반전 발견**: 부모 경로 흡수 가정을 코드 검증한 결과 **20 중 11 이 삭제 위험 확정**. (a) ✅ **안전 3**: MeterValue/ProgressBarValue/SliderOutput (부모 resolveProgressProps children 주입 + buildCatalogShapes text). (b) 🔴 **위험 11 (collection 8 + date 3)**: Tab/TabList/Tag/TreeItem/Breadcrumb/SelectIcon/SelectTrigger/SelectValue + CalendarGrid/CalendarHeader/DateInput — 부모 catalog cutover 후 부모 spec=`[]`/shell-only, 자식 catalog 미등록이라 **자식 spec.render.shapes fallback 이 유일 Skia source**. spec 삭제 시 자식 시각 Skia 소실(CSS=RAC 보존 비대칭). **삭제 전 자식 catalog 등록 또는 부모 escape/projector 흡수 필요 — step 4 차단 신규 확대**. (c) ⬜ **미검증 6**: DateSegment/TimeSegment/Description/DisclosureHeader/FieldError/Label.
4. **Switcher 재분류[완료 2026-06-04 = container shell] + Toast/Autocomplete dead 확정**. Switcher 처리는 [container shell] 정책(spec 존치 또는 frame-like generic)에 흡수.
5. **color 7 보존 처리**: spec 삭제 glob 에서 color 제외 명시.
6. **legacy/native 11 정책 결정**: TEXT_LEAF generic 전환 vs native 등록 vs 보존(Group D1 경계).
7. **import graph 0 확인** + **사용자 명시 삭제 승인** + **type-check/cross-check**.
