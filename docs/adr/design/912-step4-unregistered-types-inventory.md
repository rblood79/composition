## step 4 진입 차단 게이트 (no-go 해소 조건)

step 4 (spec 124+ 물리 삭제) 진입 전 다음 **모두 충족** 필요:

1. **[fallback 의존] value-fill 경로 대체** — **2/6 완료 (2026-06-04)**: escape 키 2개(`value_fill_bar` append / `value_fill_arc` replace) 인프라 land. **escape 로 완결된 Track sub-part 2개**: ProgressBarTrack(`f15408f29`) + MeterTrack(`24fd76172`) — DOM no-op + 자식 없음(`_hasChildren=false`)이라 escape 정상. **잔여 4개는 신규 구현 단계로 분리(선행-2b, kill criteria 발동)**: SliderTrack(SliderThumb 자식 → `_hasChildren=true` → escape `[]` 반환 + thumb 직접 그림) / ProgressCircle·ProgressBar·Meter(DOM standalone → `cutover:"catalog"` 시 DOM generic 발효로 RAC 시각 소실, DOM internal renderer wrapper 부재). **DisclosureContent 는 본 게이트에서 제외(2026-06-04 실측 = value 없는 text leaf → 게이트 #3 흡수 검증으로 이동).**
2. **[catalog 등록 후보] ~9 type 등록**: D그룹 A(Avatar 등) PrimitiveBinding 작성 + 등록 → fallback 탈출.
3. **[흡수됨] 검증 — 선행-3 완결 (2026-06-04), 전제 반전 확정**: 부모 경로 흡수 가정을 코드 검증한 결과 **25 sub-part(20 + 미검증 5 spec) 중 16 이 삭제 위험 확정**. (a) ✅ **안전 3**: MeterValue/ProgressBarValue/SliderOutput (부모 resolveProgressProps children 주입 + buildCatalogShapes text). (b) 🔴 **위험 collection 8 + date 3 = 11**: Tab/TabList/Tag/TreeItem/Breadcrumb/SelectIcon/SelectTrigger/SelectValue + CalendarGrid/CalendarHeader/DateInput — 부모 catalog cutover 후 부모 spec=`[]`/shell-only, 자식 catalog 미등록이라 **자식 spec.render.shapes fallback 이 유일 Skia source**. (c) 🔴 **위험 field/form 5 spec(미검증 5 검증 완료)**: Label/DateSegment(=TimeSegment 공유)/Description/DisclosureHeader/FieldError — 부모 catalog cutover(FAMILY_2) 또는 SHELL_ONLY(Disclosure) → `_hasChildren=true` 시 buildCatalogShapes L169 shell-only 반환(text 분기 미도달) → 자식 spec fallback(L1195/L1211)이 유일 Skia source. **공통 메커니즘**: 부모 catalog 발효 ≠ 자식 시각 흡수. spec 삭제 시 자식 시각 Skia 소실(CSS=RAC 보존 비대칭). **삭제 전 자식 catalog 등록 또는 부모 escape/projector 흡수 필요 — step 4 차단 신규 확대(위험 16)**.
4. **Switcher 재분류[완료 2026-06-04 = container shell] + Toast/Autocomplete dead 확정**. Switcher 처리는 [container shell] 정책(spec 존치 또는 frame-like generic)에 흡수.
5. **color 7 보존 + dead 2 — 선행-5 완결 (2026-06-04)**: (a) ✅ **color 7 보존**: 사용자 scope 외("color 패스") — spec 삭제 glob 에서 제외(A 섹션 정본화). (b) ✅ **Autocomplete = dead 삭제 안전**: render.shapes=`[]` + factory/palette/실사용 0. (c) 🟡 **Toast = orphan, dead 단정 보류**: factory(createToast/createToastDefinition) + spec render.shapes 실 shape + CONTAINER_DIMENSION 등록 살아있고 사용자 진입점만 부재 → 삭제 전 factory 경로 + 등록 동시 제거 필요(전제 반전, "Toast=dead" 추정 오류).
6. **legacy/native 11 정책 — 선행-4 완결 (2026-06-04), 전제 반전 확정**: "legacy/native = 단순 삭제" 가정이 틀림. 코드 검증 결과 **11 중 10 삭제 불가/위험**.
