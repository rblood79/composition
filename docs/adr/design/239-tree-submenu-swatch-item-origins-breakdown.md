### Phase 1 — Tree 항목 origin · slot · 재귀 (G1)

- **TreeItem origin**: `component-tree-item-default` (선택 상태 — 234 규칙) + `--unselected` · 상호작용 변형 (hover · pressed · focus-visible · disabled) · `--collapsed` (237 `collapsed` 층 — root 전용). 역할 자식 = 238 역할 표에 TreeItem 행 추가 (icon · label ● · description — RAC TreeItemContent 의 자유 자식이라 전부 DEFAULT_SLOT). chevron · selection · drag 는 역할이 아니다 (R2 — owner 설정 부품).
- **Tree origin**: `component-tree` 자식 = TreeItem origin instance (한 항목은 자식 항목 1 을 가진 중첩 예시) · `slot` = TreeItem origin 2.
- **재귀 slot host**: Tree 와 **TreeItem instance** 모두 host — TreeItem 의 후보는 소속 Tree 의 slot (owner 조회). "+" = 그 자리에 TreeItem instance 자식.
- **key** (리뷰 r1 h3): 238 key 규칙을 TreeItem 에도 — instance 자기 자식 (문서에 실제 노드가 있는 항목) = 노드 id (지금 Preview key `item.id` 와 같음), origin 에서 상속된 항목만 깊이마다 경로 접두. 단독 TreeItem Preview 의 `customId` key (F6) 를 같은 함수로.

### Phase 2 — 펼침 두 leg 대칭 (G2)

- **정본 = Tree `expandedKeys`** (R3 · F3 그대로). Canvas 는 접힌 TreeItem 의 자식 TreeItem 을 layout · 그리기에서 뺀다 (Disclosure `isDisclosureExpandedInContext` 와 같은 자리 — layout 과 Skia 가 한 판정 함수를 읽는다). chevron 방향 = 유효 펼침.
- **펼침 저장 배선** (리뷰 r1 h1): `expandedKeys` 를 `BUILDER_SYNCED_PREVIEW_PROPS` 에 더한다 (Disclosure `isExpanded` 선례 — builder `updateElementProps` 가 history · canonical sync · persist 를 같이 처리). 이 배선 전에는 Preview 토글이 문서에 닿지 않으므로, 펼침을 문서 상태로 삼는 결정은 이 배선과 한 Phase 다. Tree 의 `selectedKeys` 역전파는 범위 밖 (펼침과 독립 — 별도 결함으로 기록만).
- **기존 문서 이관 (hydration, 1회 · 멱등)**: 239 전에는 사용자의 펼침 선택이 문서에 쓰인 경로가 없다 (Preview 토글은 runtime 전용 · 패널 펼침 표면 0 — Phase 0 에서 쓰기 경로 표로 확인). 그래서 **`expandedKeys` 가 없거나 `[]` (factory 기본값)** 이고 중첩 TreeItem 이 있는 Tree 를 부모 항목 key 전부로 채운다 → 행 집합 그대로 (지금 전부 펼침) · Preview 는 접힘 → 펼침 (두 leg 일치). 비어 있지 않은 배열 (AI · import 가 쓴 값) 은 저작 값으로 보존 — 그 Tree 는 Canvas 에서 접힌 자식이 빠진다 (G6 변경 영역).
- **key 대응 이관** (리뷰 r1 h3 · r2): 기준은 노드 id 가 아니라 **owner Tree 별 유효 RAC key** 다. 239 는 key 가 바뀌는 원인이 둘이다 — (1) plain TreeItem → ref 이관이 노드 id 를 바꿈 (2) 상속 항목에 경로 접두 도입 (노드 id 가 같아도 Preview key 가 `A` → `T/A`, 지금 canonical Preview 는 해석된 자식 id 를 그대로 key 로 쓴다 — `CanonicalNodeRenderer.tsx:336` · `CollectionRenderers.tsx:120`). 이관 pass 는 Tree 마다 항목별 key 를 이관 전 · 후로 계산해 대응표를 만들고, 그 Tree 의 `expandedKeys` · `selectedKeys` · `defaultExpandedKeys` · `defaultSelectedKeys` 를 대응표로 바꾼다. 대응표에 없는 key 가 남는 Tree 는 이관 보류. 238 key 규칙 반영 (상속 항목 접두) 자체도 같은 대응을 요구한다 — 239 Phase 1 이 Tree 에 key 규칙을 적용하는 시점에 이 pass 를 같이 돈다.
- **chevron** (리뷰 r1 h2): 유효 펼침 항목의 chevron 은 아래 방향이다. 지금 Canvas 는 자식을 그리면서 chevron 을 오른쪽 (접힘) 으로 그린다 — 이 자체가 Preview 와 다른 발산이라, 이관 뒤 부모 항목 chevron 이 오른쪽 → 아래로 바뀌는 것은 의도된 변화다 (G6 변경 영역).
- Components 페이지 변형 노드는 강제 상태 (`--collapsed` = 접힘).
