## Context

**Domain**: D3 (시각 스타일 — catalog `COMPONENT_RULES_TABLE` + theme/tokens). D1 · D2 를 건드리지 않는다. D3 안에서의 변경은 「rule 이 쓰는 토큰 참조를 **노드 값** 도 쓴다」 — 값의 정본 (S2 설치본, ADR-295) 과 이름 (저장소) 은 그대로다.

### 문제

Design 패널에서 사용자가 Gap preset 「M」 을 고르면 문서에는 `12` (px 리터럴) 가 남고, Fill 팔레트에서 accent 600 을 고르면 `#2563ebff` 가 남는다. 테마 · 밀도 · 색 모드를 바꾸면 rule 값 (토큰 참조) 은 따라오지만 **노드에 고친 값은 영원히 그 숫자 · 그 색** 이다. 그래서 (1) 테마 전환이 사용자 컴포넌트의 절반에만 닿고, (2) 패널이 「규격 안 값인가 자유값인가」 를 구분해 보이지 못하며, (3) 그림자처럼 리터럴을 글자로 역매핑하는 우회 (`normalizeShadowForTheme`) 가 생긴다. ADR-295 가 값 층을 S2 로 맞춘 뒤 남은 일이 이것이다.

### Hard constraints

- **문서 스키마**: `visual` 은 변경 0 (F1). `fills` 색 · `layout` inset 만 참조 형을 더한다 (F8) — 사용자 결정 2.
- **마이그레이션 코드 0** (사용자 지시 2026-10-14): 기존 문서의 리터럴은 그대로 열리고 패널이 「스케일 밖」 (점 표시) 으로 보인다.
- **값 oracle** = 활성 테마 resolver snapshot (295 Decision 5) — 라벨 → 토큰 → px 표는 숫자를 손으로 적지 않는다.
- **D3 대칭**: Canvas (Skia) 와 Preview/Publish (DOM) 가 같은 노드 토큰에서 같은 픽셀 — 295 G2 두 arm 하니스 (`adr295PaletteSymmetry.browser.test.ts`) 가 oracle.
- **생성 CSS (generate-css.ts) 는 대상이 아니다** — rule 값이 아니라 노드 값만 바뀐다. Generator 의 변수 이름 `--catalog-token-*` (295 Decision 9) 을 노드도 그대로 쓴다.
- **다섯 표면 동시** — catalog (토큰 표 · 검증) · Canvas (핸들 스냅) · Design 패널 (칩 · 메뉴) · Interactions (`setColorScheme`) · Code (F4, 추가 0) 를 한 ADR 이 닫는다.
- 번들 ADR-201 상한 (Builder ≤ 1,390,000 · Preview ≤ 320,000 B) · 패널 입력 응답 60Hz floor.

### 대안 A: 현행 유지 — 리터럴 저장 + preset 값만 테마 해석값 (295 Decision 5 상태)

### 대안 D: 노드에 CSS 변수 문자열 (`var(--spacing-md)`) 저장

- 설명: 지금 preset 상수가 쓰는 모양을 그대로 문서에 저장.
- 위험: 기술 **HIGH** (길이 `var()` 는 Skia · 엔진 입력이 읽지 않고 (`cssPx` 가 `CatalogStyleValueError`) 색 변수만 일부 역해석한다 (`tokenResolver.ts:134`) — 축마다 역해석 표를 늘리는 구조. `shadowNormalize.ts:12` 는 같은 저장 안을 inset 3 레이어 · dirty baseline · 기존 문서 때문에 기각했다) / 성능 LOW / 유지보수 HIGH (빌더 chrome 변수 이름 `--spacing-*` 과 사용자 컴포넌트 변수 `--catalog-token-*` 이 갈린다 — 295 Decision 8 · 9) / 마이그레이션 MEDIUM.
- 기각: D3 대칭 위반 (Skia 미해석) · 295 의 이름 공간 결정과 충돌.

## Decision

**대안 B.** 노드 값은 기존 `TokenUse` 로 토큰을 참조하고, Design 패널은 단계 메뉴 (XS · S · M · L · XL 라벨, 토큰 원이름은 내부) 를 먼저 보이며 숫자 · hex 는 escape 로 남긴다. 아래 D1 ~ D9 가 경계다.
