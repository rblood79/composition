명도 역전 — hover 가 selected 보다 강하다
light 테마에서 hover 배경(#d4d5d5)이 실제 선택 배경(#e5e7eb)보다 어둡다. 아직 고르지도 않은 행이 고른 행보다 진하게 보인다.

왜 역전이 생기나
hover 는 --bg-inset 을 검정과 15% 섞어 만들고 (#f9fafb → #d4d5d5), 선택은 F1 때문에 --bg-muted (#e5e7eb) 로 고정된다. 두 값이 같은 명도 축 위에 있고 hover 쪽이 더 멀리 갔다. 권장안은 선택을 명도 축에서 빼내 accent bar 로 옮기므로 축 자체가 겹치지 않는다.
