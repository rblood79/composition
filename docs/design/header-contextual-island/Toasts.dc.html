우하단 토스트를 아일랜드로 — 옮길 것과 지킬 것

현재 토스트는 캔버스 우하단에 세로로 쌓인다. 아일랜드가 "시스템이 말하는 자리" 라면 토스트가 그 자리에 있어야 한다 — 지금은 알림이 두 군데(헤더에 없음 · 우하단)로 갈려 있다. 옮기면 코드에 있는 문제 하나가 같이 사라진다: 토스트는 하단 contextual action bar 와 자리를 다퉈 useActionBarClearance 훅으로 겹침을 재고 있는데, 상단으로 가면 그 충돌 자체가 없다.

종류별 매핑

종류지금 나오는 예아일랜드 표현수명이유
success 내보내기 완료 · 가져오기 완료 · 저장됨 Compact 1줄, 체크 아이콘 5초 그대로 확인만 하면 되는 것. 놓쳐도 손실이 없다
warning 중첩 규칙으로 위치 이동 (nestingNotice) Compact + 되돌리기 버튼 · Expanded 로 열면 이동 경로 8초 로 연장 되돌리기가 붙어 있다 — 5초는 문장을 읽고 누르기엔 짧다
error 내보내기 실패 · 파일 없음 · 중첩 거부 · 엔진 오류 Expanded 로 자동 승격 · 조치 버튼 · 붉은 tint 지속 — 닫아야 사라짐 지금은 5초 뒤 사라져 원인을 다시 볼 방법이 없다
info 성능 모드 진입·해제 Dot 또는 Compact 1줄 4초 배경 상태 변화. 조용해도 된다

큐 규칙

동시에 여러 건이면 최신 1건만 보이고 나머지는 +N. 아일랜드를 열면 최대 3건 목록, 그 이상은 Monitor 패널이 본체다. 지금처럼 세로로 무한히 쌓지 않는다 — 아일랜드는 하나뿐인 자리다.

가리키면 멈춤은 유지

현재 pauseToast / resumeToast 를 그대로 쓴다. 다만 아일랜드는 헤더 컨트롤도 겸해 hover 가 잦으므로, 정지는 알림이 떠 있는 동안에만 걸고 선택 컨트롤 hover 는 무시한다.

선택 컨트롤과 겹칠 때

알림 우선 — 대상 컨트롤은 오른쪽 축약 배지로 물러난다. 편집 중에 알림이 컨트롤을 통째로 밀어내면 안 되므로, 드래그·리사이즈 중에는 Split 로 떠서 양쪽을 동시에 남긴다.

아일랜드가 없는 화면

전체화면 미리보기·모달이 떠 있으면 헤더가 가려진다. 그때만 지금 위치(우하단)로 되돌아가는 폴백을 남긴다. 토스트 자체를 지우는 게 아니라 자리를 하나로 모으는 변경이다.
