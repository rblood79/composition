## P1 경계 종결과 P2 유보

P1 사전 조회는 위 폴링·signature 비교·drag revision·stale-frame 처리 **뒤**에 둔다. rendererInput/packet/layout identity와 registry/camera/overlay, retained content, contentDirty/cleanup/animation을 확인하므로 새 wake 배선을 전제로 하지 않는다. renderer의 classifier를 호출하거나 animation tick/cleanup flag를 소비하지 않는다. pending readiness target, drop indicator, 진행 중 AI는 준비 생략을 금지한다.

`FrameContentCache`는 filtered children와 실제/synthetic node Map을 한 세대만 보관한다. font/image/CanvasKit 또는 render closure를 저장하지 않는다. renderer 효과 cleanup에서 `clear()`로 참조를 해제한다. resource 완료의 기존 invalidate와 FontMgr/picture 수명 계약을 대체하지 않는다.

on-demand 전환·생산자 setter 단일화·wake mutation 대조는 미실행이다. 저사양 P1 이후 renderer idle CPU ≥30ms/s라는 재개 근거가 없으므로 P2에 필요한 모든 생산자를 지금 변경하지 않는다. 정상 idle에도 application RAF를 유지하며, 새 정보가 기존 polling에 도달하는 경로를 보존했다. forwards-fill animation record가 남아 isActive()인 경우 보수적으로 준비를 계속한다.

실행 증거는 [P1 반복 측정](p1-measurements.md)과 [종결 검증](closure.md)에 구분한다. 코드 조사와 실제 사용자 입력 검증을 서로 대체하지 않는다.
